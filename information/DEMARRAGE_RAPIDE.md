# 🚀 AirBar - Guide de Démarrage Rapide

**Commencez à utiliser AirBar en 5 minutes !**

---

## 🔐 Vos Identifiants

Vous avez **deux identifiants distincts** :

| Identifiant | Utilisation | Format |
|-------------|-------------|--------|
| **Email + Mot de passe** 📧 | Se connecter à l'app | email@example.com + 6 caractères min |
| **Code PIN** 🔢 | Valider vos achats | 4 chiffres (ex: 1234) |

> 💡 **C'est votre première fois ?** Contactez un administrateur du club pour créer votre compte.

---

## 🎯 Première Connexion

### 1️⃣ Lancer l'application

**macOS / Windows :** Double-cliquez sur l'icône AirBar

### 2️⃣ Configurer le serveur

**Si c'est votre toute première utilisation :**

1. En bas de l'écran de connexion, cliquez sur **"Configuration serveur"**
2. Entrez l'adresse fournie par votre club :
   ```
   http://adresse-serveur:8080
   ```
3. Cliquez sur **"Tester la connexion"** ✅
4. Si le test réussit, cliquez sur **"Enregistrer"**

> 📝 **Note :** Cette étape n'est nécessaire qu'une seule fois.

### 3️⃣ Se connecter

1. **Entrez votre email** (fourni par votre club)
2. **Entrez votre mot de passe** (6 caractères minimum)
3. 👁️ Cliquez sur l'icône œil pour voir ce que vous tapez
4. Cliquez sur **"Se connecter"**

---

## 🛒 Effectuer Votre Premier Achat

### Étape 1 : Ajouter des produits

**Produit normal (bouteille, canette, snack) :**
- Cliquez sur le produit
- Choisissez la quantité (boutons `−` / `+`)
- Cliquez sur **"Ajouter au panier" 🛒**

**Produit en vrac (bière pression, etc.) :**
- Cliquez sur une portion (25cl, 50cl...)
- Choisissez le nombre de portions
- Cliquez sur **"Ajouter au panier" 🛒**

### Étape 2 : Voir le panier

- Cliquez sur l'icône **panier 🛒** (en haut à droite)
- Vérifiez vos articles et le total
- Ajustez les quantités si besoin

### Étape 3 : Valider l'achat

1. Cliquez sur **"Passer la commande" 💳**
2. Vérifiez le récapitulatif
3. **Entrez votre code PIN** (4 chiffres - pas votre mot de passe !)
4. Cliquez sur **"Valider l'achat" ✅**

**C'est terminé !** 🎉 Votre compte est débité, le panier est vidé.

---

## 💵 Mode Caisse (Vente au Comptant)

**Un client de passage ou un visiteur veut acheter quelque chose ?**

> 📚 **Guide complet :** Pour comprendre en détail la différence entre achat personnel et mode caisse, consultez [Modes d'Achat](MODES_ACHAT.md)

### 1️⃣ Ouvrir le mode caisse

- Depuis la boutique, cliquez sur l'icône **💰 Caisse**

### 2️⃣ Sélectionner les produits

- Partie gauche : Cliquez sur les produits à vendre
- Partie droite : Vérifiez le panier et le total

### 3️⃣ Encaisser la vente

1. Cliquez sur **"Valider la vente" 💳**
2. **Choisissez le mode de paiement :**
   - 💵 Espèces
   - 💳 Carte bancaire
3. **Entrez VOTRE code PIN** (4 chiffres)
   - ⚠️ C'est votre PIN à vous (le vendeur), pour tracer qui a fait la vente
4. Cliquez sur **"Valider la vente" ✅**
5. **Encaissez le paiement** du client (argent ou CB)

> 💡 **Important :** 
> - Le client paie **immédiatement** (espèces ou CB)
> - Vous n'êtes **PAS débité** de votre compte
> - Votre PIN sert juste à **tracer** qui a effectué la vente
> - C'est une vente **au comptant** (pas sur compte membre)

## 📊 Consulter Votre Compte

### Votre solde

**Toujours affiché en haut de la boutique :**
- 🟢 **Vert** : Solde positif
- 🟠 **Orange** : Solde faible
- 🔴 **Rouge** : Solde négatif

### Votre historique

1. Menu **≡** (en haut à gauche)
2. Cliquez sur **"Mes transactions"**
3. Consultez tous vos achats et crédits

### Recharger votre compte

**Seul un administrateur peut créditer votre compte.**

1. Donnez votre argent à l'administrateur
2. Il crédite votre compte dans l'application
3. Votre solde est mis à jour immédiatement

## 🔐 Sécurité et Bonnes Pratiques

### ✅ À FAIRE

- 🔍 Vérifier votre solde avant d'acheter
- 🤐 Garder vos identifiants secrets (email, mot de passe, PIN)
- 🚪 Fermer l'application après utilisation
- 🔔 Signaler les produits en rupture

### ❌ À ÉVITER

- 🚫 Partager votre mot de passe ou votre PIN
- 🚫 Confondre mot de passe et code PIN
- 🚫 Laisser l'app ouverte sans surveillance
- 🚫 Valider sans vérifier le total

## ❓ Problèmes Fréquents

### "Impossible de se connecter au serveur"

**Solution :**
1. Vérifiez que le serveur est bien démarré
2. Cliquez sur **"Configuration serveur"** (en bas)
3. Testez la connexion
4. Si échec : contactez l'administrateur technique

### "Email ou mot de passe incorrect"

**Solution :**
1. Vérifiez que vous utilisez le bon **email**
2. Utilisez l'icône 👁️ pour voir votre mot de passe
3. Votre mot de passe doit faire au moins **6 caractères**
4. Si le problème persiste : demandez une réinitialisation

### "Code PIN incorrect" lors d'un achat

**Solution :**
1. Vérifiez que vous entrez bien votre **PIN** (4 chiffres)
2. **Ce n'est pas votre mot de passe !**
3. Utilisez l'icône 👁️ pour voir ce que vous tapez
4. Le PIN contient exactement **4 chiffres**
5. Si le problème persiste : demandez une réinitialisation

### "Code PIN incorrect" en mode caisse

**Solution :**
1. En mode caisse, entrez **VOTRE PIN** (le vendeur), pas celui du client
2. Votre PIN sert à authentifier qui fait la vente (traçabilité)
3. Le client de passage n'a pas besoin de compte ni de PIN
4. Si le problème persiste : vérifiez que vous utilisez bien votre PIN personnel

### "Solde insuffisant"

**Solution :**
1. Vérifiez votre solde (en haut de l'écran)
2. Rechargez votre compte auprès d'un administrateur
3. Ou retirez des articles de votre panier

### "Stock insuffisant"

**Solution :**
1. Réduisez la quantité demandée
2. Signalez le problème à un administrateur
3. Choisissez un autre produit
